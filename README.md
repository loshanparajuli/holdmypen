# holdmyPen

A simple, distraction-free note-taking app for macOS.

## Building

1. Open the project in Xcode
2. Click the Play button or press `⌘R` to build and run

## Features

- Minimal, distraction-free writing interface
- Automatic text persistence
- Clean, modern UI
- Focus on writing

## Customization

Feel free to customize the app to your liking:
- Modify colors and fonts in `ContentView.swift`
- Add features to `holdmyPenApp.swift`
- Adjust window size and layout
